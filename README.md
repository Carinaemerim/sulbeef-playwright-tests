# 🧪 Test Automation Framework - Playwright BDD

This project uses **Playwright** with **TypeScript** and **Cucumber (via playwright-bdd)** to automate functional end-to-end tests. It is configured as an **ES Module** project, leveraging native fixtures to handle dynamic authentication states smoothly.

## 📌 Prerequisites

Before running the project, ensure you have the following installed:

- **Node.js** (v18 or higher)
- **npm** (v9 or higher)

## 🛠️ Installation & Setup

1. **Clone the repository** and navigate to the project root directory.
2. **Install the dependencies**:
   ```bash
   npm install
   ```
3. **Install Playwright browsers**:
   ```bash
   npx playwright install
   ```

## 🚀 Running the Tests

Following industry best practices, all tests run in **Headless mode (in the background)** by default, making the framework fully compatible with CI/CD pipelines.

### 💻 Local Execution (Development & Debugging)

If you want to watch the tests execute by opening the browser interface (**Headed mode**):

- **Run all tests with the browser open:**
  ```bash
  npm run test:headed
  ```
- **Run a single scenario with the browser open:**
  ```bash
  npx bddgen && npx playwright test -g "Your Scenario Name" --headed
  ```
- **Open the interactive UI Mode (Best for Debugging):**
  Recommended for real-time tracking, time-travel debugging, and running isolated Gherkin scenarios with a single click:
  ```bash
  npm run test:ui
  ```

### ☁️ Headless Execution (CI/CD Default)

To run tests silently without rendering the browser UI:

- **Run all tests in headless mode:**
  ```bash
  npm run test
  ```
- **Run tests for a specific project/browser:**
  ```bash
  npx playwright test --project=chromium
  ```

## 🧹 Troubleshooting & Dynamic Caching

When working with `playwright-bdd`, changes to `.feature` text or steps parameters may occasionally cause silent compilation mismatches (e.g., _No tests found_ errors) due to local Node.js or framework caching.

If your new scenarios are not being picked up or the runner appears stuck, execute this sequence to clear everything and force a hard re-index:

```bash
# Remove old BDD temporary code, clear the npx execution cache, and recompile fresh steps
rm -rf .features-gen && npx clear-npx-cache && npx bddgen
```

## 📊 Test Reports

After the test execution is complete, you can view the detailed interactive HTML report generated by Playwright:

```bash
npm run report
```

_Note: If the report server fails to boot with an `EADDRINUSE: address already in use` error, it means an older report instance is trapping port 9323. Run `kill -9 $(lsof -t -i:9323)` on Mac/Linux or `Stop-Process -Id (Get-NetTCPConnection -LocalPort 9323).OwningProcess -Force` on Windows to free up the environment._

## ⚡ Available Shortcut Scripts

These shortcuts are configured in the `package.json` file for easier execution:

| Command               | Description                                                                                   |
| :-------------------- | :-------------------------------------------------------------------------------------------- |
| `npm run bdd:gen`     | Regenerates the JavaScript files from the `.feature` files into `.features-gen`.              |
| `npm run test`        | Hard-clears old generation cache, triggers `bddgen`, and runs all tests in **headless** mode. |
| `npm run test:headed` | Generates BDD files and runs all tests with the **browser open (Headed)**.                    |
| `npm run test:ui`     | Generates BDD files and boots up the interactive graphical **Playwright UI Mode**.            |
| `npm run report`      | Opens the last generated HTML test execution report.                                          |
